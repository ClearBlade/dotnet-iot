# dotnet-iot
An implementation of .net C# Google Cloud IoT Core client for ClearBlade IoT Core

# Nuget package
https://www.nuget.org/packages/ClearBlade.API.dotnet.client.core

# Examples
1. Look at **RunSamples.cs**.
2. Look at the **static readonly bool** values at the beginning. Setting any of those to **true** enables the corresponding function below.
3. Change the path (e.g. **projects/myProj/locations/us-central1/registries/myRegistry**) accordingly in the relevant function.
4. Look here for explanations of the example functions:  https://docs.clearblade.com/iotcore/samples
